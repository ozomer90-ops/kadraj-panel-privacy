Privacy Policy

Kadraj Publishing Panel · Operator: the owner of the Kadraj Dışı, FramePerfect Oz and ŞipŞap TV channels · Last updated: 15 November 2026 (rev. 2)

1. What this tool is

Kadraj Publishing Panel ("the tool") is a private, single-user desktop application that runs only on the operator's own computer. It is used solely to manage the operator's own YouTube channels: Kadraj Dışı, FramePerfect Oz and ŞipŞap TV. It is not offered, sold, or distributed to anyone else, and no other person can sign in to it.

The tool uses the YouTube API Services. By using the tool, the operator agrees to be bound by the YouTube Terms of Service. YouTube's data handling is governed by the Google Privacy Policy.

2. Data accessed through YouTube API Services

DataWhy
OAuth access/refresh tokens for the operator's own channelsTo upload and manage the operator's own videos. Scopes: youtube.upload, youtube, youtube.force-ssl, youtube.readonly, yt-analytics.readonly.
The operator's own channel and video data (titles, descriptions, tags, captions, thumbnails, playlists, publish schedule, privacy status)To publish, schedule and edit the operator's own content.
The operator's own YouTube Analytics reportsTo see which of the operator's own videos perform well.
Public video/channel metadata and public statistics from search results and a short list of public channels in the same nicheTopic research for the operator's own future videos. No personal data of other users (comments, subscriber lists, viewer identities) is collected.

3. Where data is stored

  • All data, including OAuth tokens, is stored only on the operator's local computer. There is no server, no cloud database, and no user accounts.
  • Data about other public channels obtained from the API is refreshed from the API or anonymized within 30 days: video titles, channel names, video IDs and links are removed. What remains are aggregate public statistics (for example view counts and ratios) with no link to a specific video or channel, kept only as permitted by YouTube's additional policies on derived metrics and data storage, together with the operator's own notes.
  • Tokens are deleted when a channel is disconnected from the tool.

4. Sharing with third parties

No YouTube API data is sold, rented or shared for advertising. The tool sends limited, non-personal data to these services, only to operate the operator's own workflow:

  • Anthropic (Claude API): draft video titles, descriptions and topic notes are sent to generate text suggestions. No OAuth tokens and no data about other users are sent.
  • Telegram: approval notifications (video title and link) are sent to the operator's own private Telegram chat.

5. Cookies and tracking

The tool runs locally and does not use cookies, analytics trackers or advertising identifiers. It does not store or access any information on the devices of other people.

6. Revoking access

Access granted to the tool can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access removes the tool's ability to use the account. Locally stored data for that channel is deleted within 7 days of revocation or on request.

7. Children

ŞipŞap TV is marked "made for kids" on YouTube. The tool does not collect any data from children or viewers. It only uploads and manages the operator's own content.

8. Contact

Questions or data requests: open an issue in this site's repository. Operator based in Türkiye.
